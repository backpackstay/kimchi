# 김장대첩 참가자 안내 페이지

백패커 김장대첩 참가자가 휴대폰으로 **일정과 공지사항**을 확인하는 페이지입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 참가자가 보는 화면 (휴대폰 우선, PC에서도 보기 좋게) |
| `schedule.xlsx` | 행사정보 · 일정 · 공지 데이터. **이 파일만 고치면 화면이 바뀝니다** |
| `intro.mp4` | 처음 들어올 때 나오는 약 3초 로고 인트로 영상 (같은 창에서 새로고침하면 다시 나오지 않음, 주소 끝에 `?nointro` 를 붙이면 생략) |

## 처음 한 번: 페이지 켜기 (GitHub Pages)

1. 이 저장소에서 **Settings → Pages** 로 이동
2. **Build and deployment → Source** 를 `Deploy from a branch` 로 선택
3. **Branch** 를 `main`, 폴더를 `/ (root)` 로 고르고 **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다
   → `https://siimba0306.github.io/kimchi/`
5. 이 주소를 참가자 공지에 올리면 끝입니다.

## 일정·공지 고치기

1. `schedule.xlsx` 를 내려받아 엑셀로 엽니다.
2. 파란 글씨 칸만 고칩니다. (시트 이름과 1행 제목은 그대로 두세요)
   - **행사정보**: 맨 위에 보이는 행사 이름·날짜·장소. `1일차 날짜`, `2일차 날짜`를 적어 두면 행사 당일 지금 진행 중인 일정이 강조됩니다.
   - **일정**: 한 줄 = 일정 하나. `일차`는 1 또는 2, 시간은 `09:00` 형식.
   - **공지**: 한 줄 = 공지 하나. `중요`에 `O` 를 적으면 맨 위에 강조됩니다.
3. 저장소에서 **Add file → Upload files** 로 같은 이름(`schedule.xlsx`)의 파일을 올리고 **Commit changes**.
4. 1~2분 뒤 참가자 화면에 반영됩니다. (새로고침 필요)

## 주의

- GitHub Pages 주소는 **누구나 볼 수 있는 공개 페이지**입니다. 참가자 연락처나 내부 메모는 넣지 마세요.
- PC에서 `index.html`을 더블클릭해서 열면 엑셀을 읽지 못해 예비 내용만 보입니다. 확인은 GitHub Pages 주소로 해 주세요.
